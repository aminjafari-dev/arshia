# دفتر زندهٔ یادگیری آرشیا

وب‌سایت محلی و فارسی برای دنبال‌کردن آموزش‌های Trade city pro. بدون وابستگی npm، بدون حساب کاربری و بدون ارسال یادداشت‌ها به سرویس بیرونی.

## اجرا

Node.js نسخهٔ ۲۲ یا جدیدتر:

```sh
cd /Volumes/Development/chatGPT/trade/arshia
npm start
```

آدرس: [http://127.0.0.1:4317](http://127.0.0.1:4317). سرور فقط روی همین دستگاه در دسترس است. برای تغییر پورت از `PORT=4318 npm start` استفاده کنید.

## امکانات

- داشبوردِ تعداد درس‌ها، پیشرفت، وضعیت فعلی، گام بعد و گزارش فعالیت.
- ۹۷ ویدیوی واقعی در سه پلی‌لیست: ۱۹، ۴۳ و ۳۵ ویدیو.
- فهرست درس‌ها با جستجو، فیلتر دوره و وضعیت.
- صفحهٔ هر درس با منبع یوتیوب، یادداشت‌های زمان‌دار و چک‌لیست بررسی.
- نقشهٔ موضوعات با تفکیک تعداد درس مرتبط از نکتهٔ ثبت‌شده.
- ثبت یادداشت شخصی، گفتهٔ مستند آرشیا یا ابهام؛ همراه بازهٔ زمانی، موضوعات و حداکثر ۳ تصویر.
- آرشیو تصاویر، بزرگ‌نمایی و دسترسی به درس مربوطه.
- ذخیرهٔ واقعی فایل‌ها، ۲۰ نسخهٔ قبلیِ داده هنگام نوشتن از API، و دریافت نسخهٔ JSON از داخل سایت.
- انتقال زندهٔ تغییرات از API یا فایل، بدون نیاز به تازه‌سازی صفحه.

در شروع **هیچ درس کاملی مطالعه نشده** و هیچ یادداشت یا تصویر آموزشی ساختگی وجود ندارد. دسته‌بندی اولیه از عنوان ویدیوها گرفته شده است. برخی عنوان‌ها در یوتیوب انگلیسی یا کوتاه‌شده نمایش داده شدند. مدت‌های دارای ثانیهٔ صفر از نمایش دقیقه‌ای یوتیوب گرفته شده‌اند و تقریبی‌اند؛ بعد از بررسی ویدیوی اصلی می‌توان زمان دقیق را ثبت کرد.

«به‌روزرسانی زنده» وضعیت اتصال صفحه به سرور است، نه نشان‌دهندهٔ مطالعهٔ خودکار در پس‌زمینه. کار فعلی عامل و آخرین زمان ثبت آن جداگانه نمایش داده می‌شود.

## محل ذخیره

- `data/state.json`: درس‌ها، موضوعات، یادداشت‌ها، وضعیت کار و رویدادها.
- `data/catalog.tsv`: فهرست منبعِ اولیه و مدت‌های نمایش‌داده‌شده.
- `screenshots/`: فایل‌های واقعی تصاویر یادداشت‌ها.
- `data/backups/`: آخرین ۲۰ نسخهٔ داده پیش از تغییر از API.
- `public/`: رابط سایت و فونت محلی Vazirmatn با مجوز OFL.

برای پشتیبان کامل، پوشه‌های `data/` و `screenshots/` را با هم کپی کنید. دکمهٔ دریافت داده‌ها فقط JSON را صادر می‌کند؛ تصاویر در پوشهٔ خودشان باقی می‌مانند. بستن صفحه چیزی را پاک نمی‌کند. برای بازکردن سایت بعد از توقف سرور، دوباره `npm start` بزنید.

## به‌روزرسانی توسط عامل یادگیری

قواعد ادامهٔ کار در `AGENTS.md` ثبت شده‌اند. به جای ویرایش مستقیم، API محلی توصیه می‌شود؛ نوشتن‌ها به ترتیب انجام می‌شوند و نسخهٔ پیشین حفظ می‌شود.

### ثبت وضعیت کار

`PATCH /api/workflow` با JSON:

```json
{
  "phase": "working",
  "title": "در حال بررسی ویدیوی معرفی",
  "detail": "توضیح دقیق کاری که واقعاً در حال انجام است",
  "next": "گام بعدی واقعی",
  "lessonId": "-5oNwNoU3Z0"
}
```

`phase`: یکی از `working`, `ready`, `paused`, `blocked`. پیش از پایان کار، وضعیت `working` را به وضعیت واقعی بعدی تغییر دهید.

### ثبت یادداشت

`POST /api/notes` با JSON و فیلدهای `lessonId`, `title`, `content`, `kind`, `startSeconds`, `endSeconds`, `topicIds`, `images`.

`kind`: یکی از `arshia`, `user`, `uncertain`. `images` آرایهٔ اختیاری در محتوا ولی اجباری در ساختار درخواست است؛ برای بدون تصویر `[]` بفرستید. هر تصویر `{ "data": "data:image/png;base64,...", "caption": "توضیح تصویر" }` است؛ حداکثر ۳ تصویر و هرکدام حداکثر ۵ مگابایت. تصاویر در بازهٔ زمانی همان یادداشت ذخیره می‌شوند. اگر تصاویر مربوط به زمان‌های متفاوت‌اند، یادداشت‌های جدا بسازید یا در ویرایش اتمی، زمان دقیق هر تصویر را ثبت کنید.

### ثبت پوشش درس

`PATCH /api/lessons/VIDEO_ID` با فیلدهای لازم:

```json
{
  "status": "studying",
  "watchedSeconds": 600,
  "summary": "خلاصهٔ مستندِ بخش بررسی‌شده",
  "coverage": { "transcript": false, "audio": false, "visuals": false, "verified": false }
}
```

وضعیت درس: `not_started`, `studying`, `review`, `completed`, `blocked`. تیک‌ها پوشش کل درس هستند؛ بررسی ۱۰ دقیقه از یک درس طولانی نباید تیک بررسی کامل را فعال کند. برای ثبت زمان دقیق منبع، `durationSeconds` و `durationApproximate: false` قابل ارسال‌اند. درس بدون یادداشت مستند آرشیا، پوشش زمانی کامل و چهار تیک بررسی تکمیل نمی‌شود.

عامل می‌تواند فایل JSON را نیز به شکل اتمی جایگزین کند؛ سرور تغییر را حدود یک ثانیه بعد می‌فرستد. در این حالت حفظ ساختار و تهیهٔ نسخهٔ قبلی بر عهدهٔ نویسنده است. سرور فایل نامعتبرِ موقت را به مرورگر نمی‌فرستد.
